Claude Cowork 简介

Claude Cowork 是 Anthropic 面向非技术办公任务推出的首款代理式 AI 产品。 它把 Claude 从对话式助手转变为行动优先的办公代理，可在安全的本地环境中规划、执行并交付工作。

关键优势

  • 无需编码：用通俗语言描述结果。
  • 本地文件访问：直接处理你授权的文件夹。
  • 专业输出：生成 Excel、PowerPoint 和 Word 文档。
  • 长时任务：无需超时即可处理长流程。

适用人群

  • 使用 Claude Desktop 的 macOS 用户。
  • Claude Max 订阅用户。

安装指南

前置条件

  1. macOS（Research Preview 要求）。
  2. 已安装 Claude Desktop。
  3. 有效的 Claude Max 订阅。

安装步骤

  1. 从 claude.ai/download 安装 Claude Desktop。
  2. 在 设置 > 订阅 中升级到 Claude Max。
  3. 在 设置 > 功能 > Cowork 中启用 Cowork。
  4. 按提示授予文件夹访问权限。

验证安装

在 Claude Desktop 中开始新对话，查看是否有 Cowork 图标。

身份验证与安全

Cowork 使用与 Anthropic 账户和 Claude Max 订阅绑定的 Claude Desktop 身份验证。

安全模型

  • VM 隔离：工作在专用虚拟机中运行。
  • 用户控制：每一步都需要你审核并批准。
  • 范围授权：只授予任务所需的文件夹。

最佳实践

  • 先从一个文件夹开始，按需扩大权限。
  • 定期检查权限。
  • 撤销不再使用的文件夹访问。

基础用法

流程

  1. 用通俗语言描述目标。
  2. 查看计划并按需调整。
  3. 在安全 VM 中批准执行。
  4. 在你授权的文件夹中接收结果。

示例命令

"创建一份汇总文档，涵盖我研究文件夹中的所有 PDF 文件"
"创建一份 PowerPoint 演示文稿，概述我的 Q4 销售数据"
"分析我数据文件夹中的所有 CSV 文件并生成汇总报告"

高级功能

子代理协作

Cowork 可以将复杂目标拆分为并行子任务，让多个代理同时工作。 

"调研 AI 领域前 5 名竞争对手并生成对比报告"

专业格式支持

  • 带公式和图表的 Excel 电子表格。
  • 带模板和版式的 PowerPoint 演示文稿。
  • 格式一致的 Word 文档。

长时任务

  • 长流程无会话超时。
  • 进度跟踪与续跑支持。
  • 你继续工作时可在后台执行。

自定义流程

  1. 定义一个流程模板。
  2. 保存以便复用。
  3. 用新的输入应用。

故障排除

未显示 Cowork 功能

  • 确认你的 Claude Max 订阅。
  • 更新 Claude Desktop 至最新版本。
  • 重启 Claude Desktop 并确认 Cowork 已启用。

权限被拒错误

  • 检查 macOS 系统设置 > 隐私与安全 > 文件与文件夹。
  • 在 Claude Desktop 设置中重新授权文件夹访问。

性能问题

  • 大文件操作需要时间。
  • 将复杂任务拆分为更小步骤。
  • 确保网络连接稳定。

获取帮助

  2. 访问 社区论坛。
  3. 问题仍然存在时联系 Anthropic 支持。
