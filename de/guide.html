Einführung in Claude Cowork

Claude Cowork ist Anthropic's erstes agentisches KI-Produkt für nicht-technische Bürotätigkeiten. Es verwandelt Claude von einem Gesprächsassistenten in einen handlungsorientierten Büroagenten, der Arbeit in einer sicheren lokalen Umgebung planen, ausführen und liefern kann.

Wesentliche Vorteile

  • Keine Programmierung nötig: Ergebnisse in Klartext beschreiben.
  • Lokaler Dateizugriff: arbeitet direkt mit Ihren autorisierten Ordnern.
  • Professionelle Ausgaben: erstellt Excel-, PowerPoint- und Word-Dokumente.
  • Lang laufende Aufgaben: bewältigt längere Workflows ohne Timeouts.

Wer kann es nutzen?

  • macOS-Nutzer mit Claude Desktop.
  • Claude-Max-Abonnenten.

Installationsanleitung

Voraussetzungen

  1. macOS (Research-Preview-Anforderung).
  2. Claude Desktop installiert.
  3. Aktives Claude-Max-Abonnement.

Schritt-für-Schritt-Installation

  1. Claude Desktop von claude.ai/download installieren.
  2. In Einstellungen > Abonnement auf Claude Max upgraden.
  3. Cowork in Einstellungen > Funktionen > Cowork aktivieren.
  4. Ordnerzugriff gewähren, wenn Sie dazu aufgefordert werden.

Installation überprüfen

Starten Sie eine neue Unterhaltung in Claude Desktop und achten Sie auf das Cowork-Symbol.

Authentifizierung und Sicherheit

Cowork verwendet die Claude-Desktop-Authentifizierung, die mit Ihrem Anthropic-Konto und dem Claude-Max-Abonnement verknüpft ist.

Sicherheitsmodell

  • VM-Isolation: die Arbeit läuft in einer dedizierten virtuellen Maschine.
  • Nutzerkontrolle: Sie prüfen und genehmigen jeden Schritt.
  • Begrenzter Zugriff: gewähren Sie nur die für eine Aufgabe benötigten Ordner.

Best Practices

  • Beginnen Sie mit einem einzelnen Ordner und erweitern Sie den Zugriff nur bei Bedarf.
  • Überprüfen Sie die Berechtigungen regelmäßig.
  • Entziehen Sie den Zugriff auf Ordner, die Sie nicht mehr verwenden.

Grundlegende Nutzung

Arbeitsablauf

  1. Beschreiben Sie Ihr Ziel in Klartext.
  2. Prüfen Sie den Plan und passen Sie ihn bei Bedarf an.
  3. Genehmigen Sie die Ausführung innerhalb der sicheren VM.
  4. Erhalten Sie die Ergebnisse in Ihren autorisierten Ordnern.

Beispielbefehle

"Erstelle ein Zusammenfassungsdokument aller PDF-Dateien in meinem Ordner Forschung"
"Erstelle eine PowerPoint-Präsentation, die meine Q4-Verkaufsdaten zusammenfasst"
"Analysiere alle CSV-Dateien in meinem Ordner Daten und erstelle einen Zusammenfassungsbericht"

Erweiterte Funktionen

Zusammenarbeit mit Unteragenten

Cowork kann komplexe Ziele in parallele Teilaufgaben aufteilen, wobei mehrere Agenten gleichzeitig arbeiten. 

"Recherchiere die 5 wichtigsten Wettbewerber im KI-Bereich und erstelle einen Vergleichsbericht"

Unterstützung professioneller Formate

  • Excel-Tabellen mit Formeln und Diagrammen.
  • PowerPoint-Präsentationen mit Vorlagen und Layouts.
  • Word-Dokumente mit konsistenter Formatierung.

Lang laufende Aufgaben

  • Keine Sitzungs-Timeouts für längere Workflows.
  • Fortschrittsverfolgung und Wiederaufnahme.
  • Ausführung im Hintergrund, während Sie weiterarbeiten.

Benutzerdefinierte Workflows

  1. Einen Workflow-Template definieren.
  2. Für die Wiederverwendung speichern.
  3. Mit neuen Eingaben anwenden.

Fehlerbehebung

Cowork-Funktion wird nicht angezeigt

  • Überprüfen Sie Ihr Claude-Max-Abonnement.
  • Aktualisieren Sie Claude Desktop auf die neueste Version.
  • Starten Sie Claude Desktop neu und bestätigen Sie, dass Cowork aktiviert ist.

Fehler „Zugriff verweigert“

  • Prüfen Sie macOS Systemeinstellungen > Sicherheit & Datenschutz > Dateien und Ordner.
  • Ordnerzugriff in den Claude-Desktop-Einstellungen erneut autorisieren.

Leistungsprobleme

  • Operationen mit großen Dateien brauchen Zeit.
  • Teilen Sie komplexe Aufgaben in kleinere Schritte.
  • Sorgen Sie für eine stabile Internetverbindung.

Hilfe erhalten

  1. Lesen Sie die offizielle Dokumentation.
  2. Besuchen Sie das Community-Forum.
  3. Kontaktieren Sie den Anthropic-Support, wenn Probleme bestehen.
